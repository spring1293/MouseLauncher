# ユビキタス言語定義

ドキュメント・コード・会話で共通して使用する用語を定義します。
新しい用語が生まれた場合はこのファイルを更新してください。

---

## ドメイン用語

| 用語 | 定義 |
|---|---|
| **ランチャー** | トリガーキー押下時にカーソル位置に表示される放射状メニュー全体のこと。「パイメニュー」とも呼ぶ |
| **パイメニュー** | 放射状に配置されたメニューUIのこと。ランチャーのUIコンポーネントとしての呼称 |
| **スロット** | パイメニュー上のアプリ割り当て枠。6つ固定で、各スロットに1つのアクションを登録できる |
| **トリガーキー** | ランチャーを呼び出すキーボードショートカットの組み合わせ（例：Alt+Space） |
| **アクション** | スロットに登録された操作。現在はアプリ起動のみ。将来的にURL・コマンド・スニペットなどに拡張予定 |
| **未割り当てスロット** | アクションが登録されていないスロット。グレーアウトで表示されクリックできない状態 |
| **オーバーレイ** | 他のウィンドウの上に透明・フレームなしで表示されるウィンドウ。パイメニューの表示に使用 |
| **常駐** | アプリがバックグラウンドで動作し続けている状態。Windows ではシステムトレイ、macOS ではメニューバーにアイコンが表示される |

---

## UI/UX用語

| 用語 | 定義 |
|---|---|
| **システムトレイ** | Windows のタスクバー右端にある常駐アプリのアイコン領域 |
| **メニューバー常駐** | macOS の画面上部メニューバー右側にアイコンを表示してアプリを常駐させること |
| **グレーアウト** | 未割り当てスロットの表示状態。視覚的に無効であることを示す |
| **フォーカス** | ウィンドウを最前面に持ってきてアクティブにすること |
| **画面端対応** | カーソルが画面端に近い場合にパイメニューの表示位置を自動調整する機能 |

## 技術用語

| 用語 | 定義 |
|---|---|
| **Tauri** | RustとWeb技術を組み合わせたデスクトップアプリケーションフレームワーク |
| **IPC（Inter-Process Communication）** | フロントエンド（WebView）とバックエンド（Rust）間の通信。Tauriの `invoke` を使用する |
| **グローバルショートカット** | 他のアプリがフォーカスを持っていても検知できるキーボードショートカット |
| **ポータブル** | インストーラーなしで単体の実行ファイルとして動作できる配布形式 |
| **アクセシビリティ権限** | macOS でグローバルキーボード・マウスイベントを監視するために必要なOS権限 |

## アクション種別の定義

`actionType` フィールドに使用する値の一覧。

| 値 | 意味 | 実装状況 |
|---|---|---|
| `"app"` | アプリケーションを起動・フォーカスする | 初期実装 |
| `"url"` | ブラウザでURLを開く | 将来実装 |
| `"command"` | シェルコマンドを実行する | 将来実装 |
| `"snippet"` | テキストをクリップボードにコピーする | 将来実装 |
