# 初回実装 要求内容

## 概要

Mouse Launcher の初回実装。パイメニューによるアプリ起動ランチャーの基本機能を実装する。

---

## 実装する機能

### 1. アプリケーションの常駐起動

- アプリ起動時にシステムトレイ（Windows）またはメニューバー（macOS）にアイコンを表示する
- バックグラウンドで常駐し、グローバルショートカットを監視し続ける
- 常駐アイコンからアプリを終了できる

### 2. パイメニュー（ランチャー）

- トリガーキー押下時にマウスカーソル位置を中心にパイメニューを表示する
- 6つのスロットを上（12時方向）から時計回りに60°間隔で配置する
- 中心に設定ボタン（歯車アイコン）を表示する
- 未割り当てスロットはグレーアウトして表示しクリックを無効にする
- アイテムにカーソルを向けてクリックすると対応するアプリを起動する
- 対象アプリが起動中の場合は既存ウィンドウをフォーカスする
- アクション実行後にパイメニューを閉じる
- Escキーまたは範囲外クリックでパイメニューを閉じる
- カーソルが画面端に近い場合は表示位置を自動調整する

### 3. 設定画面

- パイメニュー中心の設定ボタンから設定画面を開く
- 6スロットそれぞれにアプリケーションを登録・変更・削除できる
  - ファイル選択ダイアログで実行ファイルを指定する
  - 設定画面のスロット枠に実行ファイルをドラッグ&ドロップして登録する
- トリガーキーの組み合わせを変更できる
- 設定はローカルファイル（config.json）に永続化する

### 4. 初回起動時の処理

- 設定ファイルが存在しない場合はデフォルト設定で初期化する
- macOS でアクセシビリティ権限が未付与の場合、システム環境設定への誘導メッセージを表示する

---

## ユーザーストーリー

- ユーザーとして、トリガーキー（デフォルト：Ctrl+Shift+Space）を押すとカーソル位置にランチャーが表示され、目的のアプリをすぐに起動できる
- ユーザーとして、設定画面で6つのスロットに好みのアプリを登録できる
- ユーザーとして、トリガーキーを自分の好みに変更できる
- ユーザーとして、アプリをドラッグ&ドロップするだけで素早くスロットに登録できる

---

## 受け入れ条件

- [ ] Windows・macOS の両環境でアプリが起動・常駐する
- [ ] トリガーキーでどのアプリ上からでもパイメニューを呼び出せる
- [ ] パイメニューがカーソル位置を中心に表示される
- [ ] 6スロットが上から時計回りに配置される
- [ ] 未割り当てスロットがグレーアウトで表示される
- [ ] スロットクリックで対応アプリが起動・フォーカスされる
- [ ] Escキー・範囲外クリックでパイメニューが閉じる
- [ ] 設定画面でスロットにアプリを登録・変更・削除できる
- [ ] ファイル選択ダイアログとドラッグ&ドロップの両方でアプリを登録できる
- [ ] トリガーキーを変更できる
- [ ] 設定がアプリ再起動後も保持される
- [ ] macOS でアクセシビリティ未許可時に案内が表示される

---

## 制約事項

- 初回実装のアクション種別は `app`（アプリ起動）のみとする
- UIフレームワークは使用せず、Vanilla HTML/CSS/JS で実装する
- Windows 10以降・macOS 12以降を対象とする
